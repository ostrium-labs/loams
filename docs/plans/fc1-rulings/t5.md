# FC1 Task 5 — The differential harness (fork PR #2, merged 2026-10-29)

- **R5.1** Flink 2.2.1's `datagen` has no seed option. Cases may only use `kind = 'sequence'` fields, and random fields are refused when a case loads.
- **R5.2** The `values` connector only ships with Flink's tests. "Bounded values" means SQL `VALUES`.
- **R5.3** The oracle's checkpoints go to a local filesystem volume, not RustFS.
- **R5.4** The `debezium-json` format writes `-U` as `d` and `+U` as `c`. A result read back from a sink therefore holds only inserts and deletes; cases compare under that rule.
- **R5.5** A case cannot be order-sensitive and also fold its changelog into a final table (a table has no order). Such cases are refused.
- **R5.6** Recorded fixtures drop Java stack-frame lines from error responses. Successful responses are kept byte for byte.
- **R5.7** Flink's generated OpenAPI files name the result flag `queryResult`, but the gateway sends `isQueryResult`. The client follows the wire.
- **R5.8** The oracle needs `JOB_MANAGER_RPC_ADDRESS` for its TaskManager to register. Under rootless Podman the SQL Gateway starts after the TaskManager, and `up` retries up to three times (a `crun` race).
- **Result:** 20 of 20 smoke cases recorded from live Flink 2.2.1; a re-run on a fresh stack matched 20 of 20, with API v1–v4 each.
