# HE1 rulings, HE1 Task 21: The ClickHouse type system (`loams-house-types`)

Rulings made while executing Task 21 of [plan HE1](../2026-10-21-he1-loams-house-engine.md), numbered R21.1, R21.2, …. Add a row at the end; never renumber. One file per task, so parallel PRs do not conflict.

| # | Ruling | Why | Cost if wrong |
|---|---|---|---|
| R21.1 | **Every rule in `loams-house-types` is measured on the oracle, and the answers are kept as fixtures.** `scripts/house/capture-type-fixtures.sh` reads `clickhouse-server` 26.9.2.8 and writes four files. `src/data_type_families.tsv` is `system.data_type_families`: 141 families, which names are case-insensitive, and the aliases. `type_names.tsv` holds 112 spellings and their `toTypeName`. `defaults.tsv` holds `defaultValueOfTypeName` in TSV. `values.tsv` holds 45 values in TSV, CSV, JSONEachRow and Values. The parser resolves names through the families table rather than a hand-kept list: `int8` is unknown, `INT1`, `TINYINT` and `BOOLEAN` are aliases, and a SQL alias takes and ignores arguments (`VARCHAR(255)`) | Plan HE1 Task 21 | Low: a new chDB pin re-runs the script |
| R21.2 | **Canonical text as measured.** A named `Tuple` prints over several lines, indented four spaces per named-tuple level (`Tuple(\n    a String,\n    b UInt8)`); `ChType::to_compact_string` is the one-line form, used in field metadata. `JSON` prints its settings in the order written, then typed paths sorted by path (backquoted unless plain), then `SKIP` paths, then `SKIP REGEXP`. `Enum('a', 'b')` numbers from 1 and is `Enum8` unless a value needs 16 bits. `Decimal32/64/128/256(S)` print as `Decimal(9/18/38/76, S)`, and a bare `Decimal` is `Decimal(10, 0)`. `DateTime(3)` and `TIMESTAMP(3)` are `DateTime64(3)` | Oracle fixtures | Low |
| R21.3 | **The engine's Arrow layout** follows the plan's table, with every field carrying `loams.ch.type` (compact text) at every level. `Interval*` is `Int64`. A `Map` key may not be nullable (`48`). `UInt128/256`, `Int128/256`, `BFloat16`, `Nested`, `Dynamic`, `Variant`, `Time*` and geometry parse, print, and are `48` to lay out. `from_arrow` without metadata infers a type for external data: a timestamp in ms, µs or ns is `DateTime64(3/6/9)`, a struct with fields `1`, `2`, … is an unnamed tuple, and a nullable field is `Nullable` where ClickHouse allows it | Plan HE1 Task 21 | Medium: the `Dictionary(Int32, …)` key width for `LowCardinality` is a choice; HE3 may move to the Parquet dictionary's own key type |
| R21.4 | **Defaults are one-row Arrow arrays (`default_array`), not DataFusion `ScalarValue`s**, so this crate stays on Arrow only. As measured: `Date32` defaults to 1900-01-01 (its smallest value), an `Enum` to its smallest value, and `JSON(a String, b.c UInt32)` to `{"a":"","b":{"c":0}}`. An `AggregateFunction`'s default (the empty state) is `48` until Task 29 | Oracle fixtures | Low |
| R21.5 | **Value text, as measured.** TSV escapes `\`, tab, newline, CR, NUL, `\b`, `\f` and also `'` (`it\'s`). CSV quotes strings, dates, times, UUIDs and IPs, leaves numbers and `true`/`false` bare, writes a top-level tuple as one field per element, and writes other composites as a quoted string of their quoted form. JSON writes `nan`/`inf` as `null`, escapes `/` (`output_format_json_escape_forward_slashes`), leaves 64-bit integers bare (`output_format_json_quote_64bit_integers` is off in 26.9), writes named tuples as objects and map keys as strings. Composites inside TSV and Values use the quoted form with no spaces (`['a\tb','c\'d']`, `(1,'x')`, `{'k':1.5}`). Decimals drop trailing zeros. Floats use Rust's shortest round-trip digits in JavaScript's layout (plain digits for exponents -7 < e < 21, else `1e21`/`1e-7`); `Float32` uses its own shortest digits (`toFloat32(16777217)` is `16777216`) | `tests/text.rs` against `values.tsv` | Low |
