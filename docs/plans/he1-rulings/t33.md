# HE1 rulings, HE1 Task 33: Functions IV: conversions, conditionals, maths, JSON extraction

Rulings made while executing Task 33 of [plan HE1](../2026-10-21-he1-loams-house-engine.md), numbered R33.1, R33.2, …. Add a row at the end; never renumber. One file per task, so parallel PRs do not conflict.

| # | Ruling | Why | Cost if wrong |
|---|---|---|---|
| R33.1 | Task 33's functions are `ChFn`s (`loams-house-exec/src/func/typed.rs`): typed from the arguments' ClickHouse types (`loams.ch.type`) and constant values, with the result's ClickHouse type in the result field's metadata, and ClickHouse's default `NULL`/`LowCardinality` implementation as an option. Task 31's `chudf.rs` does the same for strings; the two are unified once both merge. | `toTypeName`, the formats and Task 24's analyzer read types from field metadata; one framework keeps the 70+ functions short. | Two near-identical frameworks until the unification PR (small). |
| R33.2 | Every SQL cast (`CAST(x AS T)`, `x::T`, `CAST(x, 'T')`, `_CAST(x, 'T')`) is rewritten by the guard into the engine's `_CAST(x, 'T')` UDF; no ClickHouse cast is a DataFusion `Expr::Cast` and no analyzer rule is added. Conversions run row by row over `Value`s, exact first. | DataFusion's casts differ (`CAST('abc' AS UInt8)` is `NULL` there, `6` in ClickHouse; float-to-int, dates, `Enum` by name). A UDF keeps the semantics in one place and lets `return_field_from_args` type the result from the constant type text. Task 24's tag casts stay internal. | Row-at-a-time conversions are slow on big columns; a vectorised path per common pair (Int to Int, String to number) can replace it behind the same function. |
| R33.3 | A float out of an integer type's range converts as x86's `cvttsd2si` does (the "integer indefinite" value, then the target's low bits); `accurateCast` refuses it with `70`, and refuses fractions too. | ClickHouse's `static_cast` is undefined behaviour in C++, and the oracle runs on x86-64. | An ARM oracle would differ; the oracle pins x86-64. |
| R33.4 | `toXOrZero` and `toXOrNull` take only `String`/`FixedString` (`43` otherwise); `toXOrDefault` takes any type. Text past an integer's range wraps (`toUInt8('300')` is `44`). | ClickHouse's documented behaviour; the oracle cases `to_x_or_zero_number_arg` and `to_numbers_from_strings` check both. | A triage entry and a one-line change if the oracle differs. |
| R33.5 | `if`, `multiIf`, `caseWithExpression`, `coalesce`, `ifNull`, `greatest`/`least` and `ifNotFinite` take the least supertype from Task 24's `coerce::rules::least_supertype` (`func/cond/supertype.rs` re-exports it), the rule every other expression uses. A string literal cast to `String` (a bound `{p:String}`) stays the literal, so Task 24's literal rules still read it as a constant. | One supertype rule for the whole engine; Task 24 merged first (#1300). | None beyond Task 24's own. |
| R33.6 | Values without a zone of their own are read and written in `UTC` (`SESSION_TIMEZONE`), the oracle server's zone, until `session_timezone` is honoured (Task 37); `timezone()` and `serverTimezone()` answer it. | No settings are honoured yet (D1805). | A server with another zone answers differently until Task 37. |
| R33.7 | Conditionals evaluate every branch before choosing (no short-circuit evaluation). | DataFusion evaluates a UDF's arguments eagerly; ClickHouse's `short_circuit_function_evaluation` would skip an error in a branch no row takes. | A query like `if(x = 0, 0, intDiv(1, x))` errors here; tracked as a `bug` for the clause task that adds lazy arguments. |
| R33.8 | `rand`, `rand64` and `randCanonical` use SplitMix64 seeded from the clock; the oracle compares them by type and range only. | ClickHouse's generator is not part of its contract. | None. |
| R33.9 | JSON functions read with a small validating reader of our own (`func/json/scan.rs`) that keeps raw spans, not `serde_json`: `JSONExtractRaw` returns text as written, duplicate keys take the first, and an invalid document gives the default. | simdjson's answers (raw text, first duplicate) are what ClickHouse returns; `serde_json` reformats values and keeps the last duplicate. | Corner cases of number classification (`1.0`, `-0`) may differ; the oracle triage finds them. |
| R33.10 | `currentDatabase()` is bound in `loams-house-sql`'s context (`session.rs`), which knows the statement's database; it is not in the registry. | A registry function cannot see the session. | None. |
