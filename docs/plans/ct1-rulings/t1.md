# CT1 Task 1 — Inventory audit (2026-10-29)

This audit checks §83 §4 (hops H1–H21) against the code on dev after #1566, #1570 and #1571.

**Method.** `git grep` over non-test sources in `crates/` and `fabric/crates/`:
- **listeners**: `TcpListener::bind`, `UdpSocket::bind`, `UnixListener::bind`, `axum::serve(` and tonic `Server::builder()`. This found 76 files.
- **clients**: `reqwest::Client`, `Client::builder()`, `hyper_util::client`, tonic `Channel` and `Endpoint`, and `TcpStream::connect`. This found 107 files.

Tests, benches, examples and fuzz targets are excluded. The raw lists are in the PR description. Every hit is classed below.
