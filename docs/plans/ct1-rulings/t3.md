# CT1 Task 3 — `loams-transport`: identity and the CA service (rulings)

## Part 1 (2026-10-29): identities, mTLS configurations, peer identity

This part adds the new crate `crates/loams-transport` (`publish = false`). Nothing in the product uses it yet.

- `SpiffeId` parses and formats the D2308 IDs: `spiffe://<cluster>/<node|role|svc>/<name>`.
  - It follows SPIFFE's trust-domain and segment character rules, with a maximum length of 2048 bytes.
  - It uses exactly two path segments.
  - `short()` (`role/gateway`) is the form route policies will name (Task 4).
- `tls::server_config` and `tls::client_config`:
  - TLS 1.3 only, with aws-lc-rs as an **explicit** provider (`builder_with_provider`), so the configs do not depend on any process-wide default provider;
  - client certificates are required on the server side (`WebPkiClientVerifier`);
  - one ALPN per config (`h3` or `h2`);
  - `max_early_data_size = 0` on the server and `enable_early_data = false` on the client (D2318).
- `peer::peer_identity` reads every SPIFFE URI SAN from a verified leaf, so a node certificate can carry `node/` plus its `role/` IDs. It refuses a certificate whose IDs name more than one cluster.

**R3.1 Crypto provider split.** `crates/loams` builds its existing TLS (the House link and the main-port TLS of `tls.rs`) on **ring** (`rustls` `ring` feature, `tokio-rustls` `ring`). `loams-transport` uses **aws-lc-rs** (D2306).
- Both providers can live in one binary because each config names its provider explicitly.
- Moving `crates/loams`' own TLS to aws-lc-rs is a separate change for T1 (Task 6), done when the cluster listener moves onto `loams-transport`. It is not done here.

Tests (`cargo test -p loams-transport`, 8 in total):
- `round_trips_every_kind` and `refuses_what_is_not_an_identity`;
- in-memory handshakes (no sockets), for `h3` and `h2`: `mutual_tls_names_the_peer_on_both_sides`, `a_client_from_another_ca_is_refused`, `a_client_without_a_certificate_is_refused`;
- `a_certificate_without_a_spiffe_id_has_no_identity`, which also refuses mixed clusters;
- `zero_rtt_is_off_on_both_sides` and `an_empty_bundle_is_an_error`.

Clippy passes with `-D warnings`. Buck is regenerated.
